# 소스와 직접 빌드 (개발자용)

설치만 하실 분은 이 문서가 필요 없습니다. [Releases](https://github.com/MANN1309/ev6-kr-usbwifi-dongle/releases/latest)의 USB 묶음을 쓰세요.

| 위치 | 내용 |
|---|---|
| `pkg/` | NEMESIS 패키지 본체 (스크립트, 동글 서비스, 드라이버) |
| `hmgapi_mod/` | 패키지 안에 들어가는 HMG-API 모드 소스. `stubs/`는 컴파일용 HMG-API 인터페이스 껍데기 |
| `pkg/source/driver/` | 드라이버(GPL-2.0) 소스 정보와 빌드 방법 |
| `usb/` | 설치 USB 묶음 목록 파일과 만들기 스크립트 |
| `test_offline.sh` | PC에서 돌리는 패키지 스크립트 시험 (`sh test_offline.sh`) |

## 모드와 패키지 빌드
- 필요: JDK(Java 8 대상으로 컴파일), Android SDK(`d8`, `android.jar`), Python 3 + `cryptography`
- 모드는 **본인의 서명 키**로 서명합니다. 제작자의 키는 공개하지 않습니다.
  ```bash
  mkdir -p hmgapi_mod/keys && openssl ecparam -name prime256v1 -genkey -noout -out hmgapi_mod/keys/aakeep-author.key
  bash hmgapi_mod/tools/build.sh
  ```
  다른 키로 서명한 모드는 HMG-API에서 다른 제작자의 모드로 보일 수 있습니다. 기존 모드를 지운 뒤 설치하세요.
- 환경 변수: `ANDROID_SDK`, `AAKEEP_KEY`(키 경로), `OUT_ZIP`(결과 zip), `NEMESIS_SRC` + `DESC_CHECKER`(설명 파일 검사, 선택)
- 결과: `build/usbwifi.hotspot.zip`. USB 묶음은 `sh usb/만들기.sh build/usbwifi.hotspot.zip <출력폴더>`

고쳐서 배포할 때는 [추가 조건](../ADDITIONAL-TERMS.md)을 지켜 주세요.
