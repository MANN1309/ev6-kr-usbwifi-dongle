## 고를 때 주의
- 같은 모델명이라도 **판(버전)마다 칩이 다를 수 있습니다.** 칩이 **RTL8812BU / RTL8822BU** 인지 확인하세요.
- 다음 칩은 **지원하지 않습니다**: RTL8812AU, RTL8811AU/8821AU, RTL8821CU/8811CU, RTL8851BU, MediaTek.
- 동글을 꽂으면 패키지 기록(Launch로 복사한 USB의 `EV6_LOG_…/dongle/daemon.log`, 4.13.0 이하는 `usbwifi_hotspot_log/…/daemon.log`)에 `usb: … supported` 또는
  "other chip (needs another driver)" 처럼 지원 여부가 적힙니다.
- 칩은 같은데 목록에 없는 ID라고 나오면 알려 주세요. 다음 버전에서 추가를 검토합니다.

## 🧪 실험 지원: RTL8851BU (AX900급 Wi-Fi 6 동글) — 시험판(Pre-release)에만 포함

> ⚠️ **실물 동글로 시험하지 않았습니다.** 차 커널용으로 빌드되고, 차에 올려도 멈추지 않도록 만든 것까지만 확인했습니다.
> Wi-Fi, 핫스팟, 무선 안드로이드 오토가 실제로 되는지는 **아직 모릅니다.** 써 보신 분은 결과를 알려 주세요.

| 상태 | 제품 | USB ID |
|---|---|---|
| 🧪 실험 | Realtek RTL8851BU 기본 ID (AX900 mini 등 상표 없는 동글) | 0bda:b851 |
| 🧪 실험 | TP-Link (RTL8851BU) | 3625:010b |
| 🧪 실험 | Edimax (RTL8851BU) | 7392:e611 |

- 이 칩이 **꽂혀 있을 때만** 실험 드라이버를 올립니다. T3U 같은 기존 동글을 쓰는 차에는 영향이 없습니다.
- 드라이버를 올리다가 헤드유닛이 다시 켜지면, 다음부터는 실험 드라이버를 **자동으로 끕니다**. 패키지를 다시 설치하면 다시 시도합니다.
- 상태 화면(Launch)에 `RTL8851BU experimental driver loaded` 또는 `... switched off`로 나옵니다.
- **꽂으면 CD-ROM(드라이버 설치 디스크)으로 잡히는 동글**(USB ID `0bda:1a2b`)은 Wi-Fi 모드로 바꿀 수 없어 쓸 수 없습니다.
- 드라이버: Realtek 제조사 드라이버([fofajardo/rtl8851bu](https://github.com/fofajardo/rtl8851bu), GPL-2.0)에 차량용 패치 4개. 소스: `pkg/source/driver8851/`
