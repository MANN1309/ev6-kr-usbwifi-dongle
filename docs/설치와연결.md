# 설치와 연결 방법

> ⚠️ 정차한 상태에서만 하세요. 설치·사용으로 생기는 문제의 책임은 사용자 본인에게 있습니다. ([면책 고지](../DISCLAIMER.md))

- [Releases](https://github.com/MANN1309/ev6-kr-usbwifi-dongle/releases)의 **`EV6-dongle-USB-v버전.zip`** (설치 USB 묶음)

## 헤드유닛 재시작하는 법
설치·업데이트·삭제 뒤에는 헤드유닛(내비)을 완전히 다시 켜야 합니다. **시동을 끄는 것만으로는 부족합니다.**
- **RESET 버튼:** 내비 본체의 작은 구멍을 클립이나 볼펜 끝으로 꾹 누릅니다.
- **NEMESIS Manager:** NEMESIS Manager를 열고 **재부팅**을 누릅니다.

화면이 꺼졌다가 처음부터 다시 뜨면 된 것입니다(1~2분). ⚠️ **켜진 뒤 3분 안에 재부팅을 반복하지 마세요.** HMG-API의 부팅 보호가 걸려 무선 기능이 꺼집니다.
(Korea Projection 설치 가이드의 [내비 재부팅하는 법](https://github.com/StopDragon/korea-projection/blob/main/docs/install-guide.md#내비-재부팅하는-법)과 같습니다.)

## 1단계: 설치 (처음 한 번)
1. 시동을 켜고 정차. **동글을 차 USB에 꽂아 둡니다.**
2. 설치 USB를 만듭니다. 묶음 zip을 풀고, 나온 폴더 **안의 내용**을 USB 맨 위에 복사합니다.
   ```
   USB 메모리
   ├── NEMESIS.data            ← NEMESIS가 읽는 목록 (이름 그대로)
   ├── packages/
   │   └── usbwifi.hotspot.zip ← 설치 파일 (압축 풀지 않음)
   ├── 먼저_읽어주세요.txt
   └── 설명서/                 ← 면책 고지, 이 안내, 지원 동글, 라이선스
   ```
   이미 쓰는 NEMESIS USB가 있으면 `NEMESIS.data`를 덮어쓰지 말고 [USB 구성](USB구성.md)대로 한 묶음만 추가합니다.
3. USB를 차에 꽂고 NEMESIS Manager에서 `USB WiFi dongle as built-in Wi-Fi`를 설치합니다.
4. **헤드유닛을 재시작**합니다(위 방법). 재시작 뒤 30~40초면 동글 준비 → 핫스팟 켜짐 순서로 진행됩니다.
5. 아래 "정상 동작 확인"의 ①로 패키지 상태를 확인합니다.

## 2단계: 폰 등록 (처음 한 번)
1. 폰의 안드로이드 오토 앱 설정에서 **무선 Android Auto**를 켭니다.
2. **처음 한 번은** 내비와 폰 양쪽에서 이 차/이 폰의 블루투스 등록을 지우고 **새로 등록**합니다.
3. 내비에 "무선 Android Auto 사용" 안내가 뜨면 **사용**을 누르고, 폰에 뜨는 안드로이드 오토 권한 요청도 허용합니다.
4. 폰이 차의 Wi-Fi에 저절로 붙고 내비에 안드로이드 오토 화면이 뜹니다(30초~1분).
5. 1분이 지나도 안 뜨면 폰의 **블루투스를 껐다 켭니다.**
- 아이폰과 함께 쓰는 차는 먼저 붙은 폰 하나만 연결됩니다. 안드로이드 폰으로 하려면 아이폰의 블루투스를 잠시 꺼 주세요.

## 3단계: 다음부터 연결할 때 (매번)
1. 동글은 **계속 꽂아 둡니다.** (주행 중에 뽑지 마세요.)
2. 시동을 켜고 기다리면, 폰 블루투스가 붙은 뒤 **30~40초 안에** 무선 안드로이드 오토가 저절로 연결됩니다. 폰을 만질 필요가 없습니다.
3. 연결이 멈춰 있으면 패키지가 알아서 몇 단계로 다시 시도합니다. 그래도 안 되면 폰 블루투스를 껐다 켭니다.
4. 주행 중에 잠깐 끊겼다 다시 붙으면, 그 순간의 기록이 자동으로 남습니다(아래 "문제가 있을 때").

## 정상 동작 확인
정차한 상태에서 아래를 차례로 확인하세요. 모두 맞으면 정상입니다.

**① 이 패키지 상태:** NEMESIS Manager → My Packages → `USB WiFi dongle as built-in Wi-Fi` → **Launch**. 한 줄이 나옵니다.
```
USB Wi-Fi v4: bundled driver loaded, wlan0 present, chip mark yes, hotspot signal sys.kp.aa_ap=1
```
| 항목 | 정상 | 정상이 아닐 때 |
|---|---|---|
| 드라이버 | `bundled driver loaded` | `driver NOT loaded`: 동글이 꽂혀 있는지 확인하고 재시작 / `old driver loaded (restart needed)`: 재시작 |
| 동글 | `wlan0 present` | `no wlan0 (dongle?)`: 동글을 꽂았는지, [지원 동글](지원동글.md)인지 확인. 꽂고 30초 기다린 뒤 다시 Launch |
| 칩 표시 | `chip mark yes` | `chip mark NO`: 재시작 뒤 1분 기다려 다시 확인. 계속 NO면 HMG-API 설치 확인 |
| 핫스팟 | `sys.kp.aa_ap=1` | `0`이나 빈칸: Korea Projection이 설치되어 있는지, 아래 ②를 확인 |

**② Korea Projection 상태:** NEMESIS Manager → My Packages → `Korea Projection: Wireless for Korean Cars` → **Launch**.
"준비됨" 또는 "안드로이드 오토 연결됨"이 초록으로 나오면 정상입니다.
(1.7.3까지는 무선 안드로이드 오토가 연결돼도 "지금 연결된 폰 없음"으로 보일 수 있습니다. Korea Projection의 알려진 표시 문제입니다.)

**③ 폰:** 블루투스가 차에 연결되어 있고, Wi-Fi가 차의 Wi-Fi에 연결되어 있으며, 내비에 안드로이드 오토 화면이 떠 있으면 정상입니다.

**④ 알림:** 동글을 꽂을 때 "충전 모드만 지원" / "지원하지 않는 미디어 기기" 알림이 **뜨지 않으면** 정상입니다(동글일 때만 숨깁니다).

## 업데이트
- 오류가 확인되면 수정 중이며, 수정이 끝나면 [Releases의 최신 파일](https://github.com/MANN1309/ev6-kr-usbwifi-dongle/releases/latest)에 반영됩니다.
- 최신 묶음으로 USB를 다시 만들고 NEMESIS에서 같은 방법으로 설치하면 이전 판 위에 업데이트됩니다. 그 뒤 헤드유닛을 재시작합니다.

## 삭제
1. 정차 상태에서 **NEMESIS Manager → `USB WiFi dongle as built-in Wi-Fi` → 삭제**합니다.
2. 헤드유닛을 재시작합니다. (드라이버는 재시작 때 내려갑니다.)
3. **내비 업데이트나 서비스센터 입고 전에는 먼저 삭제하는 것을 권장합니다.**

## 문제가 있을 때
- USB 메모리를 꽂으면 기록이 `usbwifi_hotspot_log/` 폴더로 자동 복사됩니다.
  연결이 끊겼던 적이 있으면 그 안에 `drop_날짜.log` 가 있습니다.
- 기록은 **개인정보를 빼고** 저장됩니다(4.11.0부터): 연락처·통화기록·문자·재생 곡·위치·전화번호·기기 고유번호·기기 이름·Wi-Fi 이름과 비밀번호 줄은 빼고,
  블루투스/Wi-Fi 주소는 끝 2자리만 남깁니다(예: `xx:xx:xx:xx:12:E4`). 파일 맨 끝의 `== privacy filter` 줄이 필터를 거쳤다는 표시입니다.
- 자동 필터가 모든 경우를 잡는다고 장담할 수는 없으니, 공개된 곳에 올리기 전에 한 번 훑어봐 주세요.
- 문의할 때 함께 알려 주세요: 펌웨어 버전, 동글 모델과 USB ID, 폰 모델, 증상과 시각.
